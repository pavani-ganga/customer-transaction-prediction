# 💳 Customer Transaction Prediction

## 📌 Project Overview

This project predicts whether a customer will make a transaction or not based on anonymized features using machine learning techniques.

## 📊 Dataset

* The dataset contains 200 anonymized features
* Target variable indicates whether a transaction occurred (0 or 1)

## 🤖 Machine Learning Models

* Logistic Regression
* Random Forest
* XGBoost

## 🤖 Final Model

* Logistic Regression (Best Performing Model)

## 📈 Model Performance

* Accuracy: 79%
* Recall: 76%
* ROC-AUC Score: 85%

## 🏆 Why Logistic Regression?

Logistic Regression provided the best balance between recall and ROC-AUC score, making it more effective in identifying customer transactions compared to other models

## 🛠️ Tools & Technologies

* Pandas

This model helps in identifying customers who are likely to make transactions, which is useful for business decision-making.
